### The 4 pillars of learning
According to cognitive science, four ingredients make learning stick. Put each piece back in place.

- **Attention** :: The brain only retains what it has selected. One task at a time!
- **Active engagement** :: Searching, predicting, trying: a passive brain learns little.
- **Feedback** :: Quickly knowing whether you were wrong, and why.
- **Consolidation** :: Sleep and spaced repetition turn effort into habit.

> The four pillars work together: if one is missing, the whole building is fragile.

### From information to memory
Not everything we perceive becomes a memory.

- **Stimuli** :: Thousands of pieces of information reach our senses every second.
- **Attention** :: We only select a small part of them.
- **Working memory** :: A few items are handled for a short moment.
- **Long-term memory** :: Only what is repeated and connected is consolidated.

> To remember, you first need to catch attention, then repeat.

### Bloom's taxonomy
Six levels of objectives, from the simplest (bottom) to the most demanding (top).

- **Create** :: Produce an original work, solution or project.
- **Evaluate** :: Justify a decision, critique an argument.
- **Analyse** :: Break down, compare, connect the parts.
- **Apply** :: Use a method in a given situation.
- **Understand** :: Explain an idea in your own words.
- **Remember** :: Recall facts and definitions.

> A good course helps learners climb the pyramid: you can only create well what you have understood.

### Kolb's learning cycle
Explore the steps one by one, or start the autoplay.

- **Concrete experience** :: Live a situation, give it a try.
- **Reflective observation** :: Step back and describe what happened.
- **Conceptualisation** :: Draw a rule, a model, a theory.
- **Active experimentation** :: Test that rule in a new situation.

---

<!-- slide: format-process -->
### Revising effectively in 5 steps
- **Read** :: A first active reading, pencil in hand.
- **Close** :: Close the book: this is where learning begins.
- **Self-test** :: Recall the essentials from memory, without looking.
- **Check** :: Compare with the course and fill the gaps.
- **Space out** :: Start again in 1 day, then 1 week, then 1 month.

> Testing yourself is far more effective than rereading: the effort of recall is what consolidates.

### Organising your work: the Eisenhower matrix
- **Schedule** :: Important but not urgent: regular revision, preparing a project.
- **Do it now** :: Important and urgent: the homework due tomorrow.
- **Drop** :: Neither important nor urgent: scrolling your news feed.
- **Delegate or limit** :: Urgent but not important: some notifications.

> Most progress happens in the "Schedule" quadrant.

### The 4 Cs
- **Critical thinking** :: Assess how reliable a piece of information and its source are.
- **Creativity** :: Imagine new solutions to a problem.
- **Collaboration** :: Build together, share roles.
- **Communication** :: Make yourself understood, in writing and orally.
